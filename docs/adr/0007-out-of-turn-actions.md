# Out-of-Turn Actions are declarations, not turns

A Game Title may declare an Action type as out of turn by requiring the literal `outOfTurn: true` in its registered Action schema. The Game Runtime accepts such an Action from any seated Player regardless of the Active Players, tolerates an index behind the current count without a Simultaneous Action Group, and leaves validity to the Machine State Handler. An undeclared Action carrying the marker is rejected, and a non-active Player's available Actions are exactly the out-of-turn types their Machine State Handler reports. Out-of-turn Actions record standing declarations whose consequences the Game State Machine later generates as System Actions, so Deterministic Execution still follows from Game State and ordered Processed Actions alone.

Because a declaration has no dependents until the machine acts on it, Undo skips out-of-turn Actions when deciding whether another Player's Action blocks Undo, re-applies them after reversing a suffix that contained them, dropping any the restored position no longer accepts (a cancel of an instruction the Undo itself removed) or would act on at once (its acting would be a turn nobody took), and never offers them as an Undo Candidate. A declaration the machine acted on in its own System Action cascade, such as an 18xx Autopass or Run Instruction declared on the declaring Player's own turn, has dependents from the moment it is recorded: Undo treats it like any other User Action, offering it as a candidate, letting it block another Player's Undo, and not re-applying it. Before this amendment such a declaration could not be undone, and undoing an earlier Action re-applied it, so its turn played itself again. To bound history growth, a title marks its declaration as a Supersedable Action ([ADR 0008](0008-supersedable-actions.md)) and keeps at most one live declaration per Player per mechanism, or per scope within it ([ADR 0008](0008-supersedable-actions.md)).

A Sequenced Out-of-Turn Action keeps the acceptance from any seated Player, but its consequences are immediate, so [ADR 0009](0009-sequenced-out-of-turn-actions.md) governs its index and Undo treatment instead.
