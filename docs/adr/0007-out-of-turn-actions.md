# Out-of-Turn Actions are declarations, not turns

A Game Title may declare an Action type as out of turn by requiring the literal `outOfTurn: true` in its registered Action schema. The Game Runtime accepts such an Action from any seated Player regardless of the Active Players, tolerates an index behind the current count without a Simultaneous Action Group, and leaves validity to the Machine State Handler. An undeclared Action carrying the marker is rejected. Out-of-turn Actions record standing declarations whose consequences the Game State Machine later generates as System Actions, so Deterministic Execution still follows from Game State and ordered Processed Actions alone.

Because a declaration has no dependents until the machine acts on it, Undo skips out-of-turn Actions when deciding whether another Player's Action blocks Undo, re-applies them after reversing a suffix that contained them, and never offers them as an Undo Candidate. To bound history growth, a host supersedes a Player's latest unconsumed declaration of the same type at the tail of history, reversing it before applying the replacement, and a title keeps at most one live declaration per Player per mechanism.
