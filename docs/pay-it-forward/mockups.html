4. How the tally gets its numbersEach charity's platform, what it exposes, and what you'd need to set up. One nightly fetch on the backend, cached; no browser polling.

CharityPlatformWhat it exposesSet-up needed
Gamers OutreachTiltify (and GoFundMe Pro)Tiltify's public API returns a campaign's amount raised, goal and donate link. It needs an application token from a free Tiltify account; tokens last two hours, so the nightly fetch requests one each run.Create a Board Together campaign under their Tiltify cause (tiltify.com/gamersoutreach). Tiltify retires a campaign after six months without a donation, so the fetch should notice retired status. If the in-person conversation yields a GoFundMe Pro page with read access instead, use that.
Board Games for the BetterGivebutterAPI needs their account's key. Their widgets (goal bar with amount raised) need their account ID and a campaign code. Campaigns, teams and members each report raised.Ask them for a Board Together campaign or team page. Then either their goal-bar widget on our page, or a restricted API key for the nightly fetch.

Caveats. Platform totals can include pledges or unsettled gifts, so the number should say "raised" not "received". The Givebutter half is not under your control until Board Games for the Better create the page.
