# 1861 UI

`@tabletop/1861-ui` is the Svelte Game Client for 1861: The Railways of the Russian Empire. It uses
the logic in `@tabletop/1861` and the shared 18xx table from `@tabletop/18xx-ui`. The map is the
boardless presentation: there is no board artwork. `pnpm --filter @tabletop/1861-ui dev` serves the
standalone harness on port 4224.
