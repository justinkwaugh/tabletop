# South African Railroads UI

`@tabletop/south-african-railroads-ui` is the Svelte Game Client for South African Railroads by John Bohrer, with its South African Railroads, Pennsylvania Railroad and Veld Railroads maps and James Geist's Texas Special map, implemented with his permission granted on 17 October 2026. It consumes the title logic from `@tabletop/south-african-railroads`.

## Development

Run `pnpm dev` in this package for the single-game dev harness. The [UI interaction visual contract](docs/ui-interaction-visual-contract.md) records the board's interaction intents and their precedence. Each map has its own board layout and terrain; [Maps](../south-african-railroads/docs/maps.md) lists what a new map needs.
