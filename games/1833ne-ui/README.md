# 1833NE UI

`@tabletop/1833ne-ui` is the Svelte Game Client for 1833NE. It uses the logic in
`@tabletop/1833ne` and the shared 18xx table from `@tabletop/18xx-ui`, adding a ferry
panel. The map is the boardless presentation. `pnpm --filter @tabletop/1833ne-ui dev`
serves the standalone harness on port 4198.
