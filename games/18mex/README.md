# 18MEX

`@tabletop/18mex` is the game logic for 18MEX: The Railroads Come to Mexico (Mark Derrick; Deep
Thought Games 2006, reprinted 2020), for 3–5 players, on the shared 18xx family runtime in
`@tabletop/18xx`.

The rules authority is the rulebook (version 1.63) with the designer's and publisher's
BoardGameGeek rulings; both are kept in `/workspace/artassets/18mex` (`rules.txt`, `rulings.md`).
`title-design.md` maps the game's mechanisms to the family support it uses, lists what this
title added to the family, and records the readings of rules the sources leave open.

Run `pnpm --filter @tabletop/18mex test` for the rulings, contract and whole-game specs.
