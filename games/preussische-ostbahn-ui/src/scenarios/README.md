# Preußische Ostbahn scenarios

The dev harness lists these under **Scenarios**. Each is a saved game with every action that led to it, so Undo and the history work; loading one again starts it over.

## Board

- **Late game.** A four-player game recorded by a scripted player, stopped at its 180th action, in Choosing Action. Every railroad has built a chain of track out of its home city, and several share cities with others. Use it to judge the board with track on it: the cubes in rural spaces, two or more railroads sharing a city, and the railroad cards with their income, treasuries and links. On a turn holding a share, choose Build track and a railroad: rings and prices appear around its chain, and each ring clicked builds a track.
