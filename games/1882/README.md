# 1882: Assiniboia

`@tabletop/1882` is the deterministic logic package for 1882: Assiniboia (Marc Voyer,
All-Aboard Games, 2–6 players), built on the 18xx family library `@tabletop/18xx`. Its
companion Game Client package is `@tabletop/1882-ui`.

Rules authority: the All-Aboard Games rulebook of 2020-08-12 and its errata, with the
designer's and community rulings from BoardGameGeek. Sources, rulings and decisions are in
[the title design note](../../research/18xx/1882-title-design.md).
