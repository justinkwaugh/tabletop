# 1828

`@tabletop/1828` is the deterministic logic package for 1828 (J C Lawrence, 3–5 players), built
on the 18xx family library `@tabletop/18xx`. Its companion Game Client package is
`@tabletop/1828-ui`.

Rules authority: the 1828 English Rules of 2022-04-19 (version 1.0-2-g54341c3), with the
designer's and community rulings from BoardGameGeek. Sources, rulings and decisions are in
[the title design note](./title-design.md).
