# 1880: China

`@tabletop/1880` is the deterministic logic package for 1880: China (Helmut Ohley and Leonhard
Orgler; Double-O Games 2010, Lookout Games 2022; 3–7 players), built on the 18xx family library
`@tabletop/18xx`. Its companion Game Client package is `@tabletop/1880-ui`.

Rules authority: the Lookout English rulebook (v1.15, 2022), with the designers' and community
rulings from BoardGameGeek. Sources, rulings and decisions are in
[the title design note](../../research/18xx/1880-title-design.md).
