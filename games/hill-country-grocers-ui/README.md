# Hill Country Grocers UI

`@tabletop/hill-country-grocers-ui` is the Svelte Game Client for Hill Country Grocers by Jake Stanley. It consumes the title logic from `@tabletop/hill-country-grocers`.

## Permission

This implementation is made with official permission from the game's designer, Jake Stanley, granted on October 6, 2026. The game's logo, cover art and company logos come from the materials he supplied.

## Development

Run `pnpm dev` in this package for the single-game dev harness. The [UI interaction visual contract](docs/ui-interaction-visual-contract.md) records the board's interaction intents and their precedence.
