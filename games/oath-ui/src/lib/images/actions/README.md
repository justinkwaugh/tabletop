# Action symbols

`action.<ActionType>.svg`, 90 × 90: the six major actions' symbols, named for the
`ActionType` value, which is the join key.

## Where they come from

Cropped from the Chancellor player board at x 68–157 and y 227, 352, 475, 677, 799 and 921.
Every player board prints the same column. Using the printed symbols means a player looking
at the screen and a player looking at their own board see the same mark.

The tile's black rounded square is kept, and the card stock outside its corners is left out.
Each crop was traced to SVG: the square and the white glyph are one filled path each, contoured
at sub-pixel precision from the anti-aliased crop, so the symbol stays sharp at any size.

## Minor actions have none

The player board prints one "Minor Actions" block for all of R-6, not a symbol per action, so
they are set as text.
