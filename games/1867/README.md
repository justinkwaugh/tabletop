# 1867

Game logic for 1867: The Railways of Canada (Ian D. Wilson, Grand Trunk Games), on the
`@tabletop/18xx` family, sharing 1861's merger rounds, loans and nationalisation with it. The rules
authority is the Grand Trunk 1861/1867 rulebook read with the designer's rulings; see
`research/18xx/1867-title-design.md` for sources, family changes and rulings.
