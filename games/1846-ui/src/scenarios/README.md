# 1846 scenarios

The dev harness lists these under **Scenarios**. Each is a three-player game in which only Illinois Central has been launched; loading one again starts it over. Regenerate them with `node scripts/build-scenarios.mjs` after building `@tabletop/1846`.

- **Obsolete 2-train in phase III.** IC bought the first 5, which started phase III, and is still buying trains with a 2, a 4 and the 5. The 2 is obsolete: its badge is crossed through in the spreadsheet's Trains row and on IC's company card, and its hover title and screen-reader text say it is obsolete. The phase III limit of 3 does not count it. The 2 is removed after IC next runs.
- **Obsolete 4 and 3/5 trains in phase IV.** IC bought the first 6, which started phase IV. Its 4 and 3/5 are obsolete and crossed through everywhere IC's trains are drawn; the 6 is not. The game is in the stock round before IC's next run.
