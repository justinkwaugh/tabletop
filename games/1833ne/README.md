# 1833NE

Game logic for 1833NE: Railroading in New England (Tom Lehmann, GMT Games), on the
`@tabletop/18xx` family. The rules authority is the GMT rulebook; see
`research/18xx/1833ne-title-design.md` for sources, family changes and open questions.

The Standard game is implemented. The Takeover game is not yet offered.
