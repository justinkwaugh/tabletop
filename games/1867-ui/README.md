# 1867 UI

`@tabletop/1867-ui` is the Svelte Game Client for 1867: The Railways of Canada. It uses the logic
in `@tabletop/1867` and the shared 18xx table from `@tabletop/18xx-ui`. The map is the boardless
presentation: there is no board artwork. `pnpm --filter @tabletop/1867-ui dev` serves the
standalone harness on port 4232.
