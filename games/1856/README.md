# 1856

`@tabletop/1856` is the deterministic logic package for 1856: Railroading in Upper Canada from
1856 (Bill Dixon, Mayfair Games, 3–6 players), built on the 18xx family library `@tabletop/18xx`.
Its companion Game Client package is `@tabletop/1856-ui`.

Rules authority: the Mayfair rulebook (the 1994 v2.2d and 1995 printed texts) with the designer's
rulings. Sources, rulings and decisions are in [the title design note](./title-design.md).
