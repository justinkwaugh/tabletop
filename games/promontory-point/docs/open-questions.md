# Promontory Point open questions

Every place the digest is silent, ambiguous or self-contradictory, and every place two readings would make different code. Each has a recommended ruling. Once answered, each becomes an `R-x.y-H<n>` entry in `rulings.md` and is struck from here.

## How to read a question

- **Q<n> <short title>** (R-x.y): the question.
    - _Readings:_ the two or more ways the rule could go, and what each changes in play.
    - _Sources:_ what the rulebook, FAQ and errata each say, quoted.
    - _Recommendation:_ the reading to take and why, or "provisional" when only the publisher can settle it.

Every question raised so far is answered and recorded in `rulings.md`; none is open. New questions are added below.
