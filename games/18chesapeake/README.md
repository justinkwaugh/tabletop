# 18Chesapeake

`@tabletop/18chesapeake` is the deterministic logic package for 18Chesapeake: The Birth of
American Railroads (Scott Petersen, All-Aboard Games, 2–6 players), built on the 18xx family
library `@tabletop/18xx`. Its companion Game Client package is `@tabletop/18chesapeake-ui`.

Rules authority: the All-Aboard Games rulebook and its errata, with the designer's and
community rulings from BoardGameGeek. Sources, rulings and decisions are in
[the title design note](./title-design.md).
