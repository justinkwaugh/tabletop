# Texas Special UI

`@tabletop/texas-special-ui` is the Svelte Game Client for Texas Special, based on SAR by John Bohrer, with that game's original map, its neutral Frontier Railroads version, the neutral Keystone Railroads map, the neutral Old Frontier Railroads map, and James Geist's Texas Special map, implemented with his permission granted on 17 October 2026. It consumes the title logic from `@tabletop/texas-special`.

## Development

Run `pnpm dev` in this package for the single-game dev harness. The [UI interaction visual contract](docs/ui-interaction-visual-contract.md) records the board's interaction intents and their precedence. Each map has its own board layout and terrain; [Maps](../texas-special/docs/maps.md) lists what a new map needs.
