# Hill Country Grocers

`@tabletop/hill-country-grocers` is the deterministic logic package for Hill Country Grocers, a game of grocer investment and expansion by Jake Stanley for 3–5 players. Its companion Game Client package is `@tabletop/hill-country-grocers-ui`.

## Permission

This implementation is made with official permission from the game's designer, Jake Stanley, granted on October 6, 2026. It follows the v2.0.0 rulebook and the components he supplied.

## Rules

The public `Definition` covers the initial share auctions, the Build Stores, Develop Cities and Auction Share actions, the company abilities, round-end dividends and the game end. Where the rulebook is silent or ambiguous, the choices made are recorded in [rules interpretations](docs/rules-interpretations.md), each backed by a test.
